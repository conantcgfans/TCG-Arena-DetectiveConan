# Detective Conan TCG - Arena Game Files

A custom Detective Conan card game for [TCG Arena](https://tcg-arena.fr), based on the official **Detective Conan Card Game** by Takara Tomy.

## Files

| File | Description |
|------|-------------|
| `Game_DetectiveConan.json` | Main game config (rules, board layout, format) |
| `DetectiveConanCards.json` | Full card database (1512 cards from official CSV) |
| `DetectiveConanDecks.json` | Sample pre-built decks |
| `Images/` | Card images (named by card_num, e.g. `B01001.jpg`) |

## Card Generation

Cards are generated by the script in `../Scripts/`:

```bash
cd ../Scripts
python generate_cards_json.py
```

The script reads `Conan TCG Database - Eng.csv` and outputs `DetectiveConanCards.json`.
Update `GITHUB_USERNAME` in the script before generating.

## Game Rules Summary

- **Deck size:** 50 cards
- **Starting hand:** 5 cards (mulligan if no Character/Partner)
- **Evidence:** 6 cards placed face-down at game start (3 in Evidence_1, 3 in Evidence_2)
- **Win condition:** Accumulate Evidence equal to the Case Level, then declare Case Solved during Deduction Phase

## Board Sections

| Section | Description |
|---------|-------------|
| **Partner** | Your Partner card (1 slot) |
| **Field** | Your Character cards on the battlefield (up to 4) |
| **Case** | The active Case card (determines win condition) |
| **Evidence_1** | Evidence cards 1–3 (face-down) |
| **Evidence_2** | Evidence cards 4–6 (face-down) |

## Card Types

| Type | Description | Plays to |
|------|-------------|----------|
| `Partner - [Color]` | Your main partner character | Partner zone |
| `Character - [Color]` | Battle characters | Field |
| `Event - [Color]` | One-time effect cards | Stack → Discard |
| `Case - [Color]` | Active case / win condition | Case zone |

**Colors:** Blue, Green, White, Red, Yellow, Black, Multi

## Card Stats

| Stat | Description |
|------|-------------|
| `cost` | Play cost (Level) |
| `ap` | Attack Power (e.g. 7000) |
| `lp` | Life Points given when KO'd (0–2) |
| `category` | Character traits (e.g. "Detective, Mouri Detective Agency") |

## Status Tokens

| Token | Meaning |
|-------|---------|
| Evidence | Collected evidence counter |
| Sleep | Card is tapped / used this turn |
| Cut-In | Activated Cut-In ability |
| Bond | Bond ability active |
| KO | Character removed from field |

## Setup Instructions

### 1. Push to GitHub & enable GitHub Pages

Push this entire repository to GitHub, then go to **Settings → Pages → Deploy from `main` branch**.

### 2. Update the GitHub username in two places

**In `Game_DetectiveConan.json`** — replace all `conantcgfans` with your actual GitHub username.

**In `../Scripts/generate_cards_json.py`** — update:
```python
GITHUB_USERNAME = "conantcgfans"
```
Then re-run the script to regenerate `DetectiveConanCards.json` with correct image URLs.

### 3. Add a card back image

Place your card back image as `Images/CardBack.jpg`.

### 4. (Optional) Add background images

Place table background images as `Images/1.jpg`, `Images/2.jpg`, `Images/3.jpg`.

### 5. (Optional) Add token images

Place PNG token images in `Images/Tokens/`:
- `Evidence.png`, `Sleep.png`, `CutIn.png`, `Bond.png`, `KO.png`

### 6. Load into TCG Arena

On [tcg-arena.fr](https://tcg-arena.fr), go to **Settings → Custom Game** and paste the URL to your hosted `Game_DetectiveConan.json`.

Your URL will be:
```
https://raw.githubusercontent.com/conantcgfans/TCG-Arena-DetectiveConan/main/Game_DetectiveConan.json
```
